## Sobre a VOLTRIX CODE

A **VOLTRIX CODE** é uma marca em desenvolvimento, criada por **Thiago Paiva**, estudante de Engenharia de Software e Técnico em Desenvolvimento de Software. Este repositório reúne estudos, projetos demonstrativos e materiais usados para construir o portfólio da empresa.

O foco inicial é atender pequenos negócios e profissionais que precisam apresentar seus serviços de forma simples e profissional na internet.

## O que estamos construindo

- **Landing pages** para apresentar um serviço ou uma oferta.
- **Sites institucionais** com informações, serviços, localização e contato.
- **Ajustes e manutenção** de páginas existentes.
- **Pequenas melhorias digitais** para facilitar o atendimento e a divulgação.

Cada trabalho é combinado de acordo com a necessidade do negócio e o escopo que a VOLTRIX CODE consegue entregar.

## Projetos demonstrativos

Os projetos abaixo são exercícios de portfólio. Os nomes e estabelecimentos são fictícios; não representam clientes atendidos.

### Barbearia Prime

Página demonstrativa para uma barbearia, com apresentação, serviços, seção sobre o espaço e chamada para contato pelo WhatsApp.

[Abrir os arquivos da Barbearia Prime](index.html)

### Sulfilm Auto Care

Página conceitual para um negócio de lavagem e cuidado automotivo. Apresenta opções como lavagem completa, insulfilm, higienização e polimento, com botões de contato por serviço.

[Abrir os arquivos da demonstração automotiva](lava-rapido/index.html)

> **Atenção:** telefone, endereço, horários e informações comerciais dessas páginas são dados de exemplo. Confirme todos os dados com o responsável antes de publicar ou apresentar a página como pertencente a uma empresa real.

## Executar localmente

Não é necessário instalar dependências ou ferramentas de compilação.

1. Baixe ou clone este repositório.
2. Abra `index.html` para visualizar a Barbearia Prime, ou `lava-rapido/index.html` para abrir a demonstração automotiva.
3. Para testar os botões de WhatsApp, substitua o número de demonstração pelo número correto no código.

As imagens e fontes são carregadas de serviços externos; é necessária conexão com a internet para exibi-las.

## Identidade visual

A marca usa preto e azul elétrico, com uma linguagem visual tecnológica e direta. A logo vetorial está em [`assets/voltrix-code.svg`](assets/voltrix-code.svg) e pode ser redimensionada sem perder qualidade.
